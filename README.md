### 🧑‍💻 About Me

I'm a Data Analyst currently working on **AI/LLM data annotation and evaluation** at **Innodata**, where I help improve the quality of large language and multimodal AI models through structured annotation, rubric-based evaluation, and multimodal data labeling.
